# D&D Tracker

Приложение для мастера Dungeons & Dragons для управления боевыми условиями персонажей во время кампании.

## Возможности

### 📊 Организация боя
- **Колонки для группировки** — создавай несколько групп персонажей (враги, союзники, нейтралы и т.д.)
- **Сортировка по инициативе** — одна кнопка и все персонажи расставлены по порядку ходов
- **Drag & Drop** — перетаскивай карточки персонажей между группами прямо во время боя

### 🎴 Карточки персонажей
- **Быстрый доступ** к основным параметрам:
  - Имя и инициатива
  - Текущие и максимальные ХП
  - Класс защиты (КД)
  - Статусы (пойзон, паралич, невидимость и т.д.)
- **Калькулятор урона/лечения** — применяй урон или исцеление одной кнопкой
- **Импорт из LSS** — загружай персонажей из файлов популярного инструмента LSS (JSON-формат)
- **Плавная анимация** появления новых карточек

### 📋 Полный редактор персонажа
Откройте детальный редактор из карточки для полного управления персонажем:

- **Основные параметры** — имя, раса, класс, бонус мастерства
- **Характеристики** (6 основных) — автоматический расчёт модификаторов
- **Спасброски** — владение спасбросками с учётом бонуса мастерства
- **Все навыки D&D 5e** — с расчётом модификаторов на основе характеристик и владения
- **Боевые параметры** — оружие, броня, инициатива
- **Заметки** — инвентарь, особенности персонажа, заметки мастера

### 🔄 Совместимость
- **Полная совместимость с LSS** — импортируй и экспортируй персонажей в формате LSS JSON
- Все изменения сохраняются с правильной структурой для переиспользования

## Технология
- **C++ + Qt6** — кроссплатформенное приложение
- **JSON** для хранения данных персонажей
- **Makefile** для сборки проекта

## Сборка

```bash
make build
make run
```

Или просто:
```bash
make
```

Очистка:
```bash
make clean
```

## Использование

1. **Запусти приложение** — откроется главное окно с одной пустой группой
2. **Создай группы** — кнопка "+ Создать новую группу"
3. **Добавляй персонажей** — кнопка "+ Персонаж" в каждой группе
4. **Импортируй LSS** — нажми кнопку "LSS" на карточке и выбери JSON-файл персонажа
5. **Управляй боем** — применяй урон, изменяй ХП, сортируй по инициативе
6. **Открывай редактор** — клик по аватару для детального редактирования
